## About the project

A Python integration project for SMBGhost research, bringing detection and exploitation components together in one repository. SMBGhost is tracked as CVE-2020-0796.

## Credits

The project README credits **chompie1337** for the original exploit and **ioncodes** for the scanner. Barriuso's repository combines these contributions in a wrapper.
